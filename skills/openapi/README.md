# OpenAPI

Manage OpenAPI specifications in Phoenix apps using open_api_spex.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill openapi -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill openapi
```

## Usage

```
/openapi help
```

## Subcommands

| Subcommand | Purpose |
|------------|---------|
| `regenerate` | Regenerate the OpenAPI spec from controller operations |
