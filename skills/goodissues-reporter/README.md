# GoodIssues Reporter

Set up and configure GoodIssuesReporter in Elixir/Phoenix applications.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill goodissues-reporter -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill goodissues-reporter
```

## Usage

```
/goodissues-reporter help
```

## Subcommands

| Subcommand | Purpose |
|------------|---------|
| `bootstrap` | Add GoodIssuesReporter to a Phoenix application |
