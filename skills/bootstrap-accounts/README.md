# Bootstrap Accounts

Bootstrap multi-tenant account-scoped dashboard with sidebar navigation, account switcher, theme toggle, and breadcrumbs in a Phoenix 1.8 app.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-accounts -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-accounts
```

## Usage

```
/bootstrap-accounts
```
