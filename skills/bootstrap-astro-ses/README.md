# Bootstrap Astro with AWS SES Form Handling

Bootstrap Astro site with AWS SES form handling.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-astro-ses -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-astro-ses
```

## Usage

```
/bootstrap-astro-ses
```
