# Bootstrap Google Analytics (GA4)

Configure Google Analytics 4 with gtag.js in a Phoenix 1.8 app.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-google-analytics -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-google-analytics
```

## Usage

```
/bootstrap-google-analytics
```
