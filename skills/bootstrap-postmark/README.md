# Bootstrap Postmark Mailer

Configure Postmark as the production email adapter for Swoosh in a Phoenix 1.8 app.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-postmark -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-postmark
```

## Usage

```
/bootstrap-postmark
```
