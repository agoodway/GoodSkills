# Bootstrap Astro Site

Bootstrap a new Astro site with Tailwind CSS v4, React, Partytown, and Kamal deployment config.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-astro -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-astro
```

