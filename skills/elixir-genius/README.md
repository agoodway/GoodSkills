# Elixir Project Architect

Expert Elixir/OTP system architect for designing production-ready systems with comprehensive documentation.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill elixir-genius -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill elixir-genius
```
