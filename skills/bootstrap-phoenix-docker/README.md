# Phoenix Docker Release Bootstrap

Generate production-ready Docker releases for Phoenix applications.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-phoenix-docker -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-phoenix-docker
```

## Usage

```
/bootstrap-phoenix-docker
```
