# Scratchpad

Manage a gitignored .scratchpad/ directory for temporary project files.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill scratchpad -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill scratchpad
```

## Usage

```
/scratchpad bootstrap
```
