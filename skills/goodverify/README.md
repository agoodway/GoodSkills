# GoodVerify

CLI client for goodverify.dev -- verify emails, phones, and addresses from the command line.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill goodverify -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill goodverify
```

## Usage

```
/goodverify help
```

## Subcommands

| Subcommand | Purpose |
|------------|---------|
| `install` | Install the goodverify CLI |
| `configure` | Set up API key and environment |
| `verify` | Verify an email, phone, or address |
| `batch` | Manage batch verification jobs |
| `usage` | Show API usage and credit balance |
| `health` | Check API health status |
