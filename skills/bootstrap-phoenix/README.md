# Bootstrap Phoenix Application

Set up a new Phoenix application with comprehensive code quality, testing, and development tooling.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-phoenix -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-phoenix
```

## Usage

```
/bootstrap-phoenix
```
