# Bootstrap Environment Banner

Add a sticky "non-production" warning banner to the top of every page in a Phoenix 1.8 app.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-env-banner -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-env-banner
```

## Usage

```
/bootstrap-env-banner
```
