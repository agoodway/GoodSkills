# Bootstrap Registration Toggle

Add ENV-based registration toggle to a Phoenix 1.8 app.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-registration-toggle -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-registration-toggle
```

## Usage

```
/bootstrap-registration-toggle
```
