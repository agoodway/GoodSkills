# Bootstrap Fly.io Env Sync Script

Bootstrap a shell script that syncs environment variables from a .env file to Fly.io secrets in configurable batches.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-fly-env-sync -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-fly-env-sync
```

## Usage

```
/bootstrap-fly-env-sync
```
