# Multi-Agent Work Review

Multi-specialist collaborative code review using parallel subagents for comprehensive analysis.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill review-work -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill review-work
```

## Usage

```
/review-work [optional file/area to focus on]
```
