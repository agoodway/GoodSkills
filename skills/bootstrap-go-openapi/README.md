# Bootstrap Go OpenAPI Client

Add oapi-codegen client generation to an existing Go project.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-go-openapi -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-go-openapi
```

## Usage

```
/bootstrap-go-openapi
```
