# Boruta

Add OAuth 2.0 and OpenID Connect provider to Phoenix apps using Boruta.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill boruta -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill boruta
```

## Usage

```
/boruta help
```

## Subcommands

| Subcommand | Purpose |
|------------|---------|
| `bootstrap` | Add OAuth 2.0 + OpenID Connect to your Phoenix app |
