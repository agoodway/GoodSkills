# Bootstrap Go CLI

Scaffold a production-ready Go CLI application using Cobra + Viper + slog.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-go-cli -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-go-cli
```

## Usage

```
/bootstrap-go-cli
```
