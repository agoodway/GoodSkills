# /document - Focused Documentation Generation

Generate focused documentation for components, functions, APIs, and features.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill document -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill document
```

## Usage

```
/document [what to document] [format: inline/api/guide/external]
```
