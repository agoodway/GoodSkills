# Multi-Agent Understanding Analysis

Multi-specialist collaborative analysis to understand how features, functions, or components work.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill understand -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill understand
```

## Usage

```
/understand [feature/function/component to analyze]
```
