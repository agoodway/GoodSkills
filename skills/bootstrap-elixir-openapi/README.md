# Bootstrap Elixir OpenAPI Client

Bootstrap an Elixir API client library from an OpenAPI 3.x spec using compile-time code generation.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-elixir-openapi -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-elixir-openapi
```

## Usage

```
/bootstrap-elixir-openapi
```
