# Bootstrap Event Subscription System

Set up a complete event-driven notification system in a Phoenix 1.8 application.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-events -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-events
```

## Usage

```
/bootstrap-events
```
