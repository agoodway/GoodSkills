# Bootstrap Zig CLI

Scaffold a production-ready Zig CLI application with zero external dependencies.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-zig-cli -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-zig-cli
```

## Usage

```
/bootstrap-zig-cli
```
