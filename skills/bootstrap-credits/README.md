# Bootstrap Credits with Stripe

Bootstrap a credit system with Stripe integration in a Phoenix 1.8 app.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-credits -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-credits
```

## Usage

```
/bootstrap-credits
```
