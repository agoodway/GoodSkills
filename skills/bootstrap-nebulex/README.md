# Bootstrap Nebulex Cache

Add Nebulex application caching to a Phoenix 1.8 app with a local in-memory adapter.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-nebulex -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-nebulex
```

## Usage

```
/bootstrap-nebulex
```
