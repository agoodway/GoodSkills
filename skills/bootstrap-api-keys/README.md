# Bootstrap API Keys

Bootstrap API key management UI and backend in a Phoenix 1.8 app.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-api-keys -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill bootstrap-api-keys
```

## Usage

```
/bootstrap-api-keys
```
