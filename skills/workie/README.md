# Workie

Manage git worktree workflows for Phoenix/Elixir applications with branch-isolated databases.

## Install

Install this skill globally:

```bash
npx skills add agoodway/GoodSkills --skill workie -g
```

Install into the current project:

```bash
npx skills add agoodway/GoodSkills --skill workie
```

## Usage

```
/workie bootstrap
```
